# Custom Domains for Landing Pages

## Status: Design

## Summary

Enable tenants to access their landing page via:

1. Their own custom domain (e.g., `www.acme-rentals.nl`)
2. A Jabaki subdomain (e.g., `acme-rentals.jabaki.nl`)

In both cases the URL in the browser stays as-is — no redirect, no rewrite visible to the visitor.
