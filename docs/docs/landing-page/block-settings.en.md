# Block Settings

## Overview

Each block on your landing page can be styled individually. Through the block settings you control the background, padding, text colour, max width and border radius per block. This allows you to create visual variation and hierarchy on your page.

Click on a block to open the right panel. The visual settings can be found under the **Settings** tab.

## Background

Each block supports three types of background:

### Solid colour

Choose a fixed background colour via the colour picker. Click on the colour field to open the picker and select a colour or enter a HEX value.

### Background image

Upload an image as background for the block. Drag a file to the upload area or click to select a file.

- **Allowed formats:** JPG, PNG, WebP, SVG
- **Maximum size:** 5 MB
- The image is automatically scaled to fill the block

### Gradient

Apply a gradient as background. You can choose from predefined gradients or enter a custom CSS gradient.

See [Gradient Backgrounds](gradients.md) for all available presets and instructions.

## Padding

Padding determines the inner spacing around the content of a block.

| Option   | Description                                   |
| -------- | --------------------------------------------- |
| compact  | Minimal spacing, suitable for compact layouts |
| normal   | Default padding                               |
| spacious | Extra spacing, suitable for hero sections     |

## Text colour

The text colour determines whether the text in the block is displayed in dark or light.

| Option | Description                                    |
| ------ | ---------------------------------------------- |
| dark   | Dark text on light background                  |
| light  | Light text on dark background                  |
| auto   | Automatic detection based on background colour |

!!! tip "Auto is the safest choice"
The **auto** option analyses the background colour and automatically chooses the most readable text colour. This prevents poor readability when you change the background later.

## Max width

The max width determines how wide the content of the block is displayed.

| Option     | Description                                  |
| ---------- | -------------------------------------------- |
| contained  | Content limited to a maximum width (centred) |
| full-width | Content stretches across the full width      |

## Border radius

The border radius determines the rounding of the corners of the block.

| Option | Description     |
| ------ | --------------- |
| none   | No rounding     |
| sm     | Slight rounding |
| md     | Medium rounding |
| lg     | Strong rounding |
