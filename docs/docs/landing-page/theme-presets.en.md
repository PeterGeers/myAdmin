# Theme Presets

## Overview

In the **Look & Feel** tab of your landing page configuration, you can choose a theme that determines the colours and fonts of your published page. A theme preset applies a coordinated combination of colours and fonts in one click, so your page instantly looks professional.

## Available presets

| Preset       | Colour characteristics     | Font characteristics      |
| ------------ | -------------------------- | ------------------------- |
| Professional | Business colours           | Clean, professional fonts |
| Warm         | Warm earth tones           | Inviting fonts            |
| Modern       | Sleek colours              | Modern sans-serif         |
| Nature       | Green and natural tones    | Organic fonts             |
| Minimal      | Neutral colours            | Minimalist                |
| Luxury       | Dark colours, gold accents | Elegant fonts             |

!!! tip "Which theme suits me?"
Choose **Professional** for a business appearance, **Warm** for a personal atmosphere, or **Modern** for a sleek, contemporary look. Not sure? You can always switch between presets without losing data.

## Choosing a preset

1. Go to **Tenant Admin** → **Landing Page** → **Look & Feel** tab
2. Browse the available themes in the preset selector
3. Click on the desired theme (e.g. **Professional** or **Warm**)
4. The colours and fonts are applied to your page immediately
5. Click **Publish** to make the changes live

!!! note "Changes are saved automatically"
After selecting a preset, the settings are saved immediately. You do not need to save separately.

## Custom theme

In addition to the predefined presets, you can choose the **Custom** option. This gives you full manual control over all colours and fonts of your page.

With a custom theme you can:

- Set each colour individually (primary, secondary, accent, background, text)
- Choose fonts for headings and body text separately
- Create a fully unique brand identity that does not match any of the standard presets

!!! warning "Mind consistency"
With a custom theme you are responsible for a good colour and font combination yourself. Always check how your page looks on both desktop and mobile.

## Reset to theme defaults

When you have selected a named theme (e.g. **Professional** or **Nature**) and then manually adjusted colours or fonts, you can always return to the default values of that theme.

1. Go to the **Look & Feel** tab
2. Click the **Reset to theme defaults** button
3. All colours and fonts are reset to the original values of the selected preset

!!! note "Only available for named themes"
The reset button is only active when a named theme (Professional, Warm, Modern, Nature, Minimal or Luxury) is selected. With the Custom option there is no default to return to.
