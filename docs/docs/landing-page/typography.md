# Typografie & Visuele Instellingen

## Overzicht

In de **Look & Feel** tab van je Landing Page configureer je de typografie en visuele stijl. Hier stel je lettertypen, witruimte, hoekafronding en schaduweffecten in die doorwerken op je gehele gepubliceerde pagina.

!!! note "Live preview"
Alle typografie-instellingen worden direct weergegeven in de preview zodat je het resultaat ziet voordat je publiceert.

## Lettertypen

Je kunt apart een lettertype kiezen voor koppen (headings) en voor lopende tekst (body). Dit geeft je flexibiliteit om bijvoorbeeld een decoratief koplettertype te combineren met een goed leesbaar bodylettertype.

| Font             | Type  | Stijl                 |
| ---------------- | ----- | --------------------- |
| System Default   | beide | Neutraal, universeel  |
| Inter            | beide | Modern sans-serif     |
| Lora             | beide | Elegant serif         |
| Poppins          | beide | Speels, afgerond      |
| Nunito           | beide | Vriendelijk, afgerond |
| Playfair Display | beide | Klassiek, decoratief  |
| Lato             | beide | Clean, professioneel  |

!!! tip "Combinatietip"
Kies een opvallend lettertype voor koppen (bijv. Playfair Display) en een neutraal lettertype voor body (bijv. Inter of Lato) voor een professionele uitstraling.

### Lettertype instellen

1. Ga naar **Tenant Admin** → **Landing Page** → **Look & Feel** tab
2. Selecteer bij **Heading font** het gewenste lettertype voor koppen
3. Selecteer bij **Body font** het gewenste lettertype voor lopende tekst
4. Bekijk het resultaat in de live preview

## Base spacing

De base spacing bepaalt de algemene witruimte tussen elementen op je pagina.

| Optie   | Beschrijving                             |
| ------- | ---------------------------------------- |
| compact | Minder witruimte, meer content zichtbaar |
| normal  | Standaard uitlijning                     |
| relaxed | Meer witruimte, rustiger beeld           |

## Border-radius

De border-radius bepaalt de hoekafronding van knoppen, kaarten en andere elementen op je pagina.

| Optie   | Beschrijving                   |
| ------- | ------------------------------ |
| sharp   | Geen afronding, scherpe hoeken |
| rounded | Lichte afronding               |
| pill    | Sterk afgerond, capsule-vorm   |

!!! tip "Visueel effect"
**Sharp** geeft een zakelijke, strakke uitstraling. **Pill** werkt goed voor speelse of moderne pagina's met grote knoppen.

## Shadow style

De shadow style bepaalt het schaduweffect op kaarten en verhoogde elementen.

| Optie    | Beschrijving              |
| -------- | ------------------------- |
| none     | Geen schaduw              |
| subtle   | Lichte schaduw            |
| medium   | Standaard schaduw         |
| dramatic | Diepe, opvallende schaduw |

!!! note "Subtiel vs. dramatic"
Een lichte schaduw (subtle) is geschikt voor minimalistische designs. Gebruik dramatic alleen als je elementen nadrukkelijk wilt laten opvallen ten opzichte van de achtergrond.
