# Typography & Visual Settings

## Overview

In the **Look & Feel** tab of your Landing Page you configure the typography and visual style. Here you set fonts, whitespace, border-radius, and shadow effects that apply to your entire published page.

!!! note "Live preview"
All typography settings are displayed directly in the preview so you can see the result before publishing.

## Fonts

You can choose a separate font for headings and for body text. This gives you the flexibility to combine, for example, a decorative heading font with a highly readable body font.

| Font             | Type | Style               |
| ---------------- | ---- | ------------------- |
| System Default   | both | Neutral, universal  |
| Inter            | both | Modern sans-serif   |
| Lora             | both | Elegant serif       |
| Poppins          | both | Playful, rounded    |
| Nunito           | both | Friendly, rounded   |
| Playfair Display | both | Classic, decorative |
| Lato             | both | Clean, professional |

!!! tip "Combination tip"
Choose a striking font for headings (e.g. Playfair Display) and a neutral font for body (e.g. Inter or Lato) for a professional appearance.

### Setting the font

1. Go to **Tenant Admin** → **Landing Page** → **Look & Feel** tab
2. Select the desired font for headings under **Heading font**
3. Select the desired font for body text under **Body font**
4. Review the result in the live preview

## Base spacing

The base spacing determines the general whitespace between elements on your page.

| Option  | Description                           |
| ------- | ------------------------------------- |
| compact | Less whitespace, more content visible |
| normal  | Standard alignment                    |
| relaxed | More whitespace, calmer appearance    |

## Border-radius

The border-radius determines the corner rounding of buttons, cards, and other elements on your page.

| Option  | Description                    |
| ------- | ------------------------------ |
| sharp   | No rounding, sharp corners     |
| rounded | Slight rounding                |
| pill    | Heavily rounded, capsule shape |

!!! tip "Visual effect"
**Sharp** gives a businesslike, clean appearance. **Pill** works well for playful or modern pages with large buttons.

## Shadow style

The shadow style determines the shadow effect on cards and elevated elements.

| Option   | Description            |
| -------- | ---------------------- |
| none     | No shadow              |
| subtle   | Light shadow           |
| medium   | Standard shadow        |
| dramatic | Deep, prominent shadow |

!!! note "Subtle vs. dramatic"
A light shadow (subtle) is suitable for minimalist designs. Use dramatic only when you want elements to stand out prominently against the background.
