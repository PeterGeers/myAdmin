# Blokinstellingen

## Overzicht

Elk blok op je landing page kan individueel worden vormgegeven. Via de blokinstellingen bepaal je de achtergrond, padding, tekstkleur, maximale breedte en rand-radius per blok. Zo creëer je visuele variatie en hiërarchie op je pagina.

Klik op een blok om het rechterpaneel te openen. De visuele instellingen vind je onder het tabblad **Instellingen**.

## Achtergrond

Elk blok ondersteunt drie typen achtergrond:

### Effen kleur

Kies een vaste achtergrondkleur via de kleurenkiezer. Klik op het kleurveld om de picker te openen en selecteer een kleur of voer een HEX-waarde in.

### Achtergrondafbeelding

Upload een afbeelding als achtergrond voor het blok. Sleep een bestand naar het uploadgebied of klik om een bestand te selecteren.

- **Toegestane formaten:** JPG, PNG, WebP, SVG
- **Maximale grootte:** 5 MB
- De afbeelding wordt automatisch geschaald om het blok te vullen

### Verloop (Gradient)

Pas een verloop (gradient) toe als achtergrond. Je kunt kiezen uit voorgedefinieerde verlopen of een eigen CSS-verloop invoeren.

Zie [Verlopen achtergronden](gradients.md) voor alle beschikbare presets en instructies.

## Padding

Padding bepaalt de binnenruimte rond de content van een blok.

| Optie    | Beschrijving                                    |
| -------- | ----------------------------------------------- |
| compact  | Minimale ruimte, geschikt voor compacte layouts |
| normal   | Standaard padding                               |
| spacious | Extra ruimte, geschikt voor hero secties        |

## Tekstkleur

De tekstkleur bepaalt of de tekst in het blok donker of licht wordt weergegeven.

| Optie | Beschrijving                                        |
| ----- | --------------------------------------------------- |
| dark  | Donkere tekst op lichte achtergrond                 |
| light | Lichte tekst op donkere achtergrond                 |
| auto  | Automatische detectie op basis van achtergrondkleur |

!!! tip "Auto is de veiligste keuze"
De optie **auto** analyseert de achtergrondkleur en kiest automatisch de best leesbare tekstkleur. Dit voorkomt slechte leesbaarheid wanneer je de achtergrond later wijzigt.

## Maximale breedte

De maximale breedte bepaalt hoe breed de content van het blok wordt weergegeven.

| Optie      | Beschrijving                                           |
| ---------- | ------------------------------------------------------ |
| contained  | Content beperkt tot een maximale breedte (gecentreerd) |
| full-width | Content strekt zich uit over de volledige breedte      |

## Rand-radius

De rand-radius bepaalt de afronding van de hoeken van het blok.

| Optie | Beschrijving         |
| ----- | -------------------- |
| none  | Geen afronding       |
| sm    | Lichte afronding     |
| md    | Gemiddelde afronding |
| lg    | Sterke afronding     |
